# Touchpad Keymap Layer PRD

## 背景与目标

**问题**: macOS 用户在文本编辑时，频繁需要从主键区移动到方向键/功能键区（如方向键、Home、End），打断输入流。

**解决方案**: 开发一个 Electron 应用，利用触摸板作为临时层切换器——单指放在触摸板上时，主键盘进入自定义按键层，将常用编辑键（如 i/k/j/l）映射到方向键等功能。

**目标用户**: macOS 用户，习惯触摸板操作，追求高效文本编辑体验。

**核心价值**: 手不离主键区，通过触摸板临时切换按键层，完成快速导航和编辑。

## 需求详述

### R01 触摸板层触发机制

**用户故事**: 作为 macOS 用户，我希望单指静止放在触摸板上时进入自定义按键层，手指离开后立即回到正常层，以便临时使用映射按键。

**场景**:

- **WHEN** 用户将单指放在触摸板上 **THEN** 系统检测到触摸事件并进入 Layer 2（自定义按键层）
- **WHEN** 用户手指离开触摸板 **THEN** 系统立即退出 Layer 2，回到 Layer 1（正常键盘）
- **WHEN** 用户在 Layer 2 期间按键后手指未离开 **THEN** 系统保持在 Layer 2，直到手指离开

**验收标准**:
1. 单指接触检测延迟 < 100ms
2. 手指离开检测立即生效，无缓冲延迟
3. 多指触摸不触发 Layer 2（防止误触）
4. 触摸板移动不影响层状态（静止/移动都算"接触中"）

---

### R02 按键拦截与映射

**用户故事**: 作为用户，我希望在自定义层内，指定按键被完全拦截并执行映射功能，原按键功能暂时不可用。

**场景**:

- **WHEN** 系统在 Layer 2 且用户按下映射键（如 `i`）**THEN** 系统发送映射后的键事件（如 `↑`）
- **WHEN** 系统在 Layer 2 且用户按下未映射键 **THEN** 按键正常通过（不拦截）
- **WHEN** 系统在 Layer 1 且用户按下任何键 **THEN** 按键正常通过（无拦截）

**验收标准**:
1. 默认映射：
   - `i` → `↑` (上方向键)
   - `k` → `↓` (下方向键)
   - `j` → `←` (左方向键)
   - `l` → `→` (右方向键)
   - `u` → `Home`
   - `o` → `End`
2. 拦截只在 Layer 2 生效，Layer 1 原按键功能正常
3. 映射键事件发送至当前焦点应用
4. 支持单键映射（暂不支持组合键映射）

---

### R03 配置持久化

**用户故事**: 作为用户，我希望自定义的映射规则能保存到配置文件，应用重启后仍然有效。

**场景**:

- **WHEN** 用户在配置界面修改映射规则并保存 **THEN** 规则写入 JSON 配置文件
- **WHEN** 应用启动时 **THEN** 自动加载配置文件中的映射规则
- **WHEN** 配置文件不存在或格式错误 **THEN** 使用默认映射规则并生成新配置文件

**验收标准**:
1. 配置文件路径：`~/Library/Application Support/touchpad-keymap-layer/config.json`
2. JSON 格式，包含 `mappings` 数组
3. 每个映射包含：`from`（源键）、`to`（目标键）、`toType`（key/command）
4. 配置文件变更后无需重启应用（或提供重载按钮）

---

### R04 状态栏图标反馈

**用户故事**: 作为用户，我希望通过菜单栏图标直观感知当前是否处于自定义按键层。

**场景**:

- **WHEN** 应用在后台运行 **THEN** 菜单栏显示默认图标（如 ⌨️ 灰色）
- **WHEN** 进入 Layer 2（单指触摸触摸板）**THEN** 菜单栏图标变为激活状态（如 ⌨️ 蓝色/高亮）
- **WHEN** 退出 Layer 2（手指离开）**THEN** 菜单栏图标恢复默认状态

**验收标准**:
1. 菜单栏图标两种状态：默认（Layer 1）、激活（Layer 2）
2. 状态切换延迟 < 50ms
3. 点击图标显示应用窗口（配置界面）
4. 图标适配 macOS 深色/浅色模式

---

### R05 映射配置界面

**用户故事**: 作为用户，我希望通过简易界面配置按键映射规则，而非手动编辑 JSON。

**场景**:

- **WHEN** 用户点击菜单栏图标或 Dock 图标 **THEN** 打开配置窗口
- **WHEN** 用户在配置界面点击"添加映射" **THEN** 弹出输入框捕获源键和目标功能
- **WHEN** 用户删除映射并保存 **THEN** 配置文件更新，映射立即生效

**验收标准**:
1. 界面展示当前所有映射规则列表
2. 支持添加新映射（选择/输入源键、选择目标功能）
3. 支持删除现有映射
4. 支持重置为默认映射
5. 保存按钮触发配置写入和重载
6. 界面简洁，使用 Electron 原生或轻量 UI 框架

## 非功能性需求

| 类别 | 要求 |
|------|------|
| **平台** | 仅支持 macOS（10.15+），需 Accessibility 权限 |
| **性能** | 触摸板检测延迟 < 100ms，按键映射延迟 < 50ms |
| **权限** | 需要 macOS Accessibility 权限获取全局按键事件 |
| **资源占用** | 后台运行内存占用 < 100MB |
| **安装** | 提供 .dmg 安装包或 zip 解压即用 |

## 开放问题

1. **触摸板检测精度**: 是否需要在设置中提供"触摸灵敏度"调节？
2. **冲突处理**: 如果目标应用本身有自定义快捷键，是否可能出现冲突？如何提示用户？
3. **映射目标范围**: 是否支持映射到组合键（如 Cmd+C）或系统命令？
4. **国际化**: 是否支持非英语键盘布局的映射配置？
